# Infinite Legion: Wildland Expedition

[Play now / 立即遊玩](https://zianyu503-art.github.io/infinite-legion-wildland-expedition/)

A bilingual Traditional Chinese / English Godot action game with an infinite procedural wildland, army recruitment, 57 permanent troop abilities, nation warfare, castle conquest, touch controls, three major bosses, and an optional 24-hour VIP trial featuring seamless terrain and readable animated stick-figure armies with distinct friendly and enemy silhouettes.

這是一款支援繁體中文／英文的 Godot 動作戰鬥遊戲，包含無限程序荒原、軍隊招募、57 種士兵永久能力、國家戰爭、城堡征服、觸控雙搖桿、三大 Boss，以及可免費試玩 24 小時的 VIP 無縫地形；新版直立火柴人為每種友軍與敵軍提供不同頭飾、武器及輪廓。

The repository root contains the compiled GitHub Pages build; the Godot 4.6 source project is under `source/`.
