# Infinite Legion: Wildland Expedition

[Play now / 立即遊玩](https://zianyu503-art.github.io/infinite-legion-wildland-expedition/)

A bilingual Traditional Chinese / English Godot action game with an infinite procedural wildland, army recruitment, castle conquest, touch controls, and the Corrupt Python Emperor world boss.

這是一款支援繁體中文／英文的 Godot 動作戰鬥遊戲，包含無限程序荒原、軍隊招募、城堡征服、觸控雙搖桿，以及腐沼蟒皇世界 Boss。

This public repository contains only the compiled web build used by GitHub Pages.
